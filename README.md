# Municipal Solid Waste Route Optimizer

## Problem Statement

A city sanitation management portal that ingests ultrasonic fill-level data from smart trash bins, plans optimized collection routes for garbage trucks, and tracks missed-pickup citizen complaints.

## Actors

- Sanitation Supervisor
- Truck Driver

## Deliverables

- Functional Requirements
- Non-Functional Requirements
- UML Use-Case Diagram
- Use-Case Flow Specification

## Technology

Requirements Engineering and UML Use-Case Modelling
